# Kairos Echo v1.0.0

This release establishes a versioned baseline of the reproducible Python coherence simulator and browser reflection tool.

## Included

- Seeded deterministic simulation
- Coherence, distortion, and stability dynamics
- Guardian Veto™ modeled guardrail
- CLI run, summary, logging, and reflection modes
- Standalone browser interface
- Optional Plotly visualization

## Verify

```bash
python kairos_echo.py --mode run --steps 500 --seed 42
python kairos_echo.py --mode summary
```

## Scope

Kairos Echo is a poetic, contemplative research tool. It is not therapy, meditation instruction, spiritual authority, or a measurement of consciousness.
